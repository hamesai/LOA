Library of Alexandria

Courses

Each course is its own workspace: slides, notes, practice, quizzes, tools, a ledger and a data record. Open one to work in it.

Import a save

Bring your progress over from another device. Open a backup file made with Back up everything in the Ledger of any course, and its courses, ticks, notes, ledger and slide positions are restored in this browser.

The backup is a .json file. Copy it to this phone first, for example through Drive or email.

Adding a course

Small Scale Greenhouse is the template. Every course follows the same pattern.

  1. Ask Claude: run library of alexandria on your subject. It scopes the course and writes the library.
  2. Claude scaffolds a course from _template/ with new_course.py, which creates the pack, the module lesson files and the page entries.
  3. Each lesson is written from primary sources read in full, with numbered citations, figures, worked examples and checks. The slide deck builds itself from the lessons.
  4. The new course appears above. Nothing else on this page needs editing.

Belt progress

A belt is earned when every module it needs is complete in the ledger.

Review today

Retrieval practice: answer from memory, then check. Cards come from modules you have started and return on a schedule, so what you miss comes back sooner.

Modules

Click anywhere on a module row to open its page. The slides, notes, practice, quiz and tools all live inside the module. Tick it, or use Mark complete, to log a completion. Remove completion takes you back, and both are kept in the history.

Resources

Videos, papers, books, magazines, references and image searches, tagged to modules. "Verified" means the page was located in-session, not that every source was read in full.

Data built from the ledger

Each metric you log becomes a series. Pick one to see it over time.

Ledger

Log what you did. Module completions drive the belts, and measurements and harvests build the data series below. Every entry is kept in the History below.

How far the sources were read

This course grows two ways. Entries you add are kept in this browser and can be downloaded as JSON or CSV. Ask Claude to import your downloaded ledger, attach resources, or extend a lesson, and it updates the course files next to this page.
